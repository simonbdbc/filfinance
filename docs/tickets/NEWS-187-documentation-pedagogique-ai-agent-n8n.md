# NEWS-187 - Documentation pédagogique AI Agent n8n

## Objectif

Documenter le fonctionnement du résumé journalier n8n pour que le mini-projet
serve de support d'apprentissage.

## Scope

- Expliquer AI Agent vs appel HTTP simple.
- Expliquer OpenRouter, Structured Output Parser et callback backend.
- Expliquer l'allowlist de sources web.
- Expliquer que Piper est le seul TTS supporté.
- Expliquer la production `main`, le rollback et la désactivation.

## Critères d'acceptation

- `n8n/docs/README_N8N_FILFINANCE.md` couvre le setup local.
- Le README couvre les credentials n8n sans secret versionné.
- `docs/ENVIRONMENT-FILES.md` et `docs/PRODUCTION-FINAL-RUNBOOK.md`
  documentent les variables daily summary.
