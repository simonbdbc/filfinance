# Tickets NEWS

Ce dossier regroupe les tickets de developpement `NEWS-*`.

- Les EPIC restent dans `docs/epics/`.
- Les liens entre tickets utilisent des chemins relatifs locaux `./NEWS-*.md`.
- Les liens depuis un ticket vers une doc racine utilisent `../`.

Cette separation garde `docs/` lisible: cadrage global et runbooks a la racine, EPIC dans `epics/`, tickets d'execution dans `tickets/`.
